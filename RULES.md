# Rules

## Theme changes

- Every theme change must be dynamic. Do not hardcode text, images, links, colors, spacing, or other content in the code.
- Everything must be editable from the Shopify theme editor through section, block, or theme settings.
- Give new settings sensible defaults so the theme looks right before the merchant changes anything.

## Commits

- After every change, the AI must suggest a commit title for that change.
- The AI must never commit by itself. The developer reviews the change and commits it manually.
